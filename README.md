# Brand Aerospace Website

Static website built from the agreed plan:

- Main navigation: Home, Traditional Marketing, Digital Marketing, Supplies, Blog.
- Website concept PDF used for navigation/page structure only.
- Updated wording is based on the newer company profile direction.
- Catalogue offers are used without showing public prices.
- Company documents, certificates, bank letters and reference letters are not included.
- Contact/quote form opens a prepared WhatsApp message.

## Files

- `index.html` - Home page
- `traditional-marketing.html` - Traditional Marketing page
- `digital-marketing.html` - Digital Marketing page
- `supplies.html` - Supplies page
- `blog.html` - Blog page
- `contact.html` - Request Quote page
- `assets/css/styles.css` - Site styling
- `assets/js/main.js` - Mobile menu and WhatsApp quote form
- `assets/img/` - Web-ready visuals extracted/enhanced from provided PDFs
- `robots.txt` and `sitemap.xml` - Basic SEO files

## Deployment

Upload the whole folder to Netlify, Vercel, cPanel, or GitHub Pages. Do not upload the original PDFs publicly unless the client approves because the catalogue contains prices and the profile contains company documents.

## Notes

Before launch, confirm final contact email, phone number, official domain, and whether the client wants the blog to be active immediately or hidden until articles are written.
